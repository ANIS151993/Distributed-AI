# Overleaf Support Package

This folder mirrors the manuscript files for direct upload to Overleaf.

## Included

- `IEEE_Distributed_AI_Ensemble.pdf`
- `IEEE_Distributed_AI_Ensemble.docx`
- `IEEE_Distributed_AI_Ensemble.tex`
- `IEEE_Distributed_AI_Ensemble.txt`
- `references.bib`
- `figures/` (all PNG assets used in the paper)
- `tables/` (all LaTeX tables generated from benchmark artifacts)

## Public Access Note

These files sit in the repository directly, but the public site gates the corresponding download links
(including the Overleaf ZIP) behind a follow-GitHub, subscribe-YouTube, send-permission-request, and
password unlock flow at `docs/index.html#paper`.

## Notes

- Table and figure assets are already generated from repository artifacts.
- If metrics are rerun, regenerate tables/figures first, then refresh this package.
